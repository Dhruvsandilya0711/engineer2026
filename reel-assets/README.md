## Things to know

- **Bullseye:** in the current game a bullseye (100 pts) can't be reached. Hits are tested once per tick, and the
  9 px core is never reached before the 34 px outer ring registers the hit. The gameplay clip therefore shows ring
  hits, as the original footage did.
- **Event count:** the reel says "40 EVENTS"; the site currently lists 28.
